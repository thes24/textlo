# Textlo
A real-time chat application built with MERN stack

## Tech Stack

### Frontend
- React (Vite)
- Socket.io-client
- Tailwind CSS
- React Router

### Backend
- Node.js + Express
- Socket.io
- MongoDB + Mongoose
- JWT Authentication
- Cloudinary (File Upload)

## Installation & Setup

### Backend
``` bash
cd server
npm install
npm run dev
```

### Frontend
``` bash
cd client
npm install
npm run dev
```

## Features
- [ ] User Authentication (Register/Login)
- [ ] Real-time 1:1 Chat
- [ ] Group Chat
